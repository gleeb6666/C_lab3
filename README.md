# Лабораторна робота 3, варіант 10: виконання обчислення за схемою

Схема №10, `nt=4`, `a=7, b=9, c=4, d=8, g=7, h=9, i=8, j=5, k=4, n=3`
(набори `e`, `f`, `m` у схемі №10 відсутні).

Компілятор: MSVC 19.44 (Visual Studio 2022), x64, C++20.

## Схема

```
a: S → T        c: T → Q        d: B → P        j: P → F
b: S → B        h: T → P        i: B → Q        n: Q → F
                g: T → F        k: B → F
```

Залежності: `c, g, h` після `a`; `d, i, k` після `b`; `j` після `h` і `d`; `n` після `c` і `i`.

## Розподіл по потоках

Усього 64 дії, 4 потоки, тому нижня межа — 16 одиниць часу. Наведений розподіл її досягає:
жоден потік не простоює.

| Потік | Дії |
|---|---|
| 1 | a1–a4, h1–h5, c1–c4, j1–j3 |
| 2 | a5–a7, b1, h6–h9, g1–g7, j4 |
| 3 | b2–b5, d1–d4, i1–i4, k1–k2, n1, j5 |
| 4 | b6–b9, d5–d8, i5–i8, k3–k4, n2–n3 |

Синхронізація — `std::latch` для кожного набору, від якого залежать інші (`a, b, c, d, h, i`).
Після кожної дії такого набору виконується `count_down()`, перед залежними діями потік викликає `wait()`.
Діаграма: `diagram/schedule.svg` (`diagram/schedule.png`).

## Структура

| Файл | Призначення |
|---|---|
| `src/main.cpp` | точка входу, вимірювання тривалості обчислення |

| `src/computation.*` | жорстко заданий розподіл дій по потоках і точки синхронізації |
| `results/results.txt` | вихід програми |
| `diagram/` | діаграма розподілу обчислень по потоках |

